## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Amit01verma/DETTROIN-INT-Amit-Website.git
```

Go to the project folder:

```bash
cd DETTROIN-INT-Amit-Website
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Create a production build:

```bash
npm run build
```
